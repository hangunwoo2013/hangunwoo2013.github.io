# B-ROUTE Local-first 1.4 — 구현 상태

## 이번 버전 목표
외부 교통 API 키와 GTFS 데이터 연결 전에 지인 시연이 가능하도록 주요 UI 흐름을 준비합니다. 실제 정보가 아닌 부분은 명확히 시연 데이터로 표시합니다.

## 구현 완료
- `?demo=1`로 켜지는 시연 모드 및 주의 배너
- 버스 전용 / 철도 전용 / 버스+철도 3개 시연 예제
- 가상 노선 단계 및 지도 경로선 표시
- 예제 경로 생성 후 자동 기기 저장
- 실제 GTFS 검색 성공 결과 자동 기기 저장
- 저장 시 경로 계산 스냅샷 함께 보관
- 저장 경로 재열기 시 저장 당시의 경로 결과 표시
- 개별 `.broute` JSON 파일 내보내기 및 가져오기
- 상단 문의 버튼으로 피드백 화면 이동
- 서비스 워커 캐시 버전 업데이트
- Python 컴파일 및 JavaScript 구문 검사

## 저장 및 공유의 현재 범위
- 저장소는 기존 LocalStorage를 유지합니다.
- 같은 브라우저 원본(동일 도메인·브라우저) 안에서 저장 데이터에 접근할 수 있습니다.
- 다른 기기 이동은 `.broute` 또는 전체 JSON 파일 내보내기/가져오기로 진행합니다.
- 피드백은 현재 기기에서만 저장됩니다. 별도 파일로 내보내 총괄자에게 전달해야 합니다.
- Google 계정 로그인이 되더라도 이번 버전에서 클라우드 저장이 자동으로 연결되는 것은 아닙니다.

## 미구현 / API 연동 이후 작업
- 실제 TAGO/Kakao 등 API 키 연결 및 실사용 검증
- 지역별 GTFS 공급원 확보, 데이터 갱신 파이프라인, 실제 버스·철도 시간표 경로 검증
- IndexedDB로 기기 저장 계층 이전 및 저장 공간 관리
- 영구 데이터베이스와 객체 스토리지(COS 등) 연결
- 계정별 1GB 클라우드 제한, 클라우드 동기화 및 충돌 해결
- 서버에 피드백 접수·총괄자 답변 기능 연결
- 관리판 통계, 감사 로그, 설정 및 교통 데이터 롤백 UI

## 검증
- Python `py_compile` 통과
- 메인 페이지 JavaScript `node --check` 통과
- HTML ID 중복 검사 통과
- 시연 예제 3개의 설정/경로 데이터/시간표 합계 검사 수행
- EdgeOne 배포 테스트는 진행하지 않았습니다.

## 안전한 사용 안내
- 실제 경로 검색은 현재 GTFS 데이터가 등록된 범위에서만 가능하며, 이 배포 ZIP에는 GTFS 피드가 포함되지 않습니다.
- `?demo=1` 시연 결과는 가상 노선·시간표이므로 실제 이동 안내에 사용하면 안 됩니다.
- LocalStorage는 브라우저 데이터 삭제, 저장소 제한, 프라이빗 모드 등에 영향을 받을 수 있으며 무기한 보존을 보장하지 않습니다.

## 최종 재검증 결과
- API `/health` 응답 버전 `1.4.0` 확인
- 비로그인 `/auth/me`가 미인증으로 응답하는 것 확인
- Google OAuth 미설정 시 로그인 비활성 상태 확인
- 비로그인 `/admin/config/status`가 HTTP 401로 차단되는 것 확인
- 세 시연 예제별 교통수단 구성 및 승차+도보+대기 합계가 총 소요시간과 일치하는 것 확인
- 지도 라이브러리 부재 시 경로선 그리기 코드를 안전하게 건너뛰는 방어 처리
- 브라우저 시각 UI 테스트 및 EdgeOne 배포 테스트는 수행하지 않음
