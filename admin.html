API 및 저장소 연결

프로젝트 초대 메일은 Resend 서버 API로 전송합니다. 이 화면에는 발신 주소와 사용량만 표시하며 API 키는 표시하지 않습니다.

실제 교통 API 연결 검사

총괄자만 실행할 수 있습니다. 서버 Secret의 공공데이터포털 키로 각 API 상품의 개별 작업을 검사합니다. 키 등록만으로 활용신청 승인이 보장되지는 않습니다. API 키 원문은 브라우저나 결과 화면에 표시하지 않으며, 응답 성공도 전국 데이터 완전성이나 경로 엔진 반영을 의미하지 않습니다.

아직 연결 검사를 실행하지 않았습니다.

운영 설정

총괄자 API 키 등록 방법

  1. GitHub 저장소 설정과 Cloud Run 서비스 환경변수를 엽니다.
  2. 교통 API·OAuth 비밀값·DATABASE_URL·COS 자격 증명을 Secret Manager에 등록합니다.
  3. GitHub Actions가 Secret Manager를 참조하도록 설정합니다.
  4. 배포 후 관리판에서 연결 상태를 다시 확인합니다.
절대로 API 키 원문을 브라우저나 이 관리판의 일반 설정란에 입력하지 마세요. 변경 이력에는 비밀값을 기록하지 않습니다. 비밀값 교체는 Google Secret Manager에서 진행합니다.
